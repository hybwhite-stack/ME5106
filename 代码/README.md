# 运行当前 P/V 预测

在仓库根目录安装 `numpy`、`scikit-learn` 后运行：

```bash
python 代码/双头融合_训练与预测未知组.py
```

程序读取 `代码/输入特征` 中的逐组派生特征，只用 46 组正式标签重新训练功率与速度双头，并写出 `结果表/未知三组_双头融合候选预测.csv`。49 号的 425 W 暂定参考不进入程序。41、43、49 的标签不参与拟合；速度由模型投票得出。

`训练策略_统一五折筛选前五并预测.py` 和 `已训练模型_前五方案.json` 是较早的**单一岭回归特征筛选基线**，保留作历史消融复现，并非当前双头融合预测入口。旧脚本运行时会重写其对应的旧结果表，勿将旧的五折排名当成未知三组准确率。

若要重新运行 1000 套功率特征/权重组合比较：

```bash
python 代码/多候选特征组合与融合比较.py
```

这会把完整明细写到 `结果表/多候选搜索复现`；仓库已附有对应的 `结果表/全部融合组合比较.csv` 等对照表。该搜索可能需要约 1–2 分钟，且其 46 组内部数字只是探索结果。程序不以 49 号 425 W 参考值优化权重。
