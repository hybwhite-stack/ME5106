# 特征物理假设与后续实验

课程项目要求把方法、特征工程和物理考虑讲清楚；项目说明第 7 页特别提醒不要缺乏物理依据地盲试模型。以下是假设与待验证的预测关系，**不是从现有数据证明的因果律**。

| 特征组 | 声学解释与可能关联 | 主要混杂因素 | 下一步验证 |
|---|---|---|---|
| RMS、平均绝对峰值 | 声压波动强度可能随熔池、蒸汽羽流和飞溅改变；也可能受功率及扫描速度共同影响。 | 麦克风距离、增益、轨迹位置、异常冲击。 | 固定速度档比较功率档；同时看五轨均值与离散程度。 |
| 频谱质心 | 描述能量在频率轴上的“重心”；可能反映声源机制或工况转变。 | 滤波截止、传感器频响、背景噪声。 | 在固定幅值特征后单独加入/移除；比较不同速度档方向。 |
| 8–20、20–40、40–80 kHz 能量比例 | 比较不同频带的相对能量分配，有机会比总幅值更不受录音增益影响。 | 频带划分、8 kHz 高通、不同频带的传感器灵敏度。 | 按频带分别做增量/剔除实验；检查三段比例和为 1 带来的冗余。 |
| 起始尖峰比 | 捕捉入轨瞬态相对稳态的强弱，可能与激光进入粉层时的短时过程有关。 | 分段起点偏差、偶发撞击、只有个别 Track 出现。 | 固定其他特征做 R01/R02、R03/R04 成对比较，并核查尖峰所在的原始波形。 |
| 早/中/尾时段变化 | 加工声学活动可能随熔池形成、稳定和结束而演化；时间位置可能比整条 Track 平均值更有辨识力。 | Track 边界、不同持续时间、尾部可能含关光后的衰减。 | 复核激光实际开关时间；分别比较早/中与尾/中两组增量，做边界灵敏度。 |
| Track 持续时间与五轨波动 | 扫描速度可能改变材料受激时间；五轨波动可能显示工况稳定性。 | 轨迹长度未知、切段阈值、位置变化。 | 在速度分类中固定其他特征做剔除实验，报告各速度档混淆矩阵。 |

声源并非只有激光参数。课件第 13 页列出 keyhole/蒸汽羽流、气流、粉末与飞溅碰撞、开裂、环境噪声等可能来源；第 14 页强调实验条件不明时须谨慎解释声音。当前 8 kHz 高通是本项目采用的处理选择，不等于 8 kHz 以下对全部工况都无信息。若更改滤波方案，必须重新分段、抽特征并在**相同折**上重做比较。

## 建议的下一批有控制实验

1. **频谱贡献**：以 R07 为固定参照，分别移除频谱质心、8–20 kHz 比例、40–80 kHz 比例；同时保留只用幅值和只用频谱的小型参照。每次只改一个预先声明的因素。
2. **P、V 分开验证**：功率报告 46 组的 ±20% 命中数、平均相对误差、MAE 和逐功率档误差；速度报告 550/700/850 mm/s 的总体及逐档准确率、混淆矩阵。不要把功率方案排名借给速度模型。
3. **物理分层检查**：在同一速度档内比较功率变化，在同一功率档内比较速度变化。对 175 W 高速组与更高功率组分别检查幅值和起始尖峰，不用硬阈值代替证据。
4. **边界与去噪敏感性**：针对代表性与误差较大的 SampleID 核查五条 Track 的起止位置、尾部衰减和异常尖峰。只有当输入定义一致时，才把新特征结果与 R01–R08 放在同一表中。

小样本下每个候选都可能偶然获益。新增实验应先记录假设、固定折和主指标，再运行并完整报告正负结果；如果继续按同一 46 组反复筛选，交叉验证的最佳分数会越来越偏乐观。真正的泛化能力还需要新采集或严格隔离的样本。
