# ME5106：用声学信号预测未知组的激光功率 P 与扫描速度 V

> **新增结构对照：**功率头现已比较单 GBDT、单加权岭、两者 25%/75% 混合及原三模型混合；速度头始终是同一个三模型投票。双功率模型在 49 号预测 **390.66 W / 850 mm/s**，按 425 W 暂定参考的事后误差为 **8.08%**；46 组内部 P/V 同时达标 40/46，与原三功率模型相同。它是**看过 49 号参考后的新候选**，不是盲测提升；原候选预测仍保留在下表。详情见[功率单/双头对照](报告/功率单双头与速度独立对照.md)。

项目最终交付是对未给出参数的 SampleID 41、43、49 预测 **P（W）和 V（mm/s）**，并在正式答案公布后计算误差。每组五条 Track 先汇总成一个样本；46 个已有正式标签的组用于建立模型，未知组不参与拟合。20% 是功率预测的目标误差上限，不代表已有三组独立测试成绩。
